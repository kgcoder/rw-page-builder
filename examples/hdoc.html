This page is an Embedded HDOC shown in the Reader's Web reader UI. It is a plain HTML file: the reader script, its styles and a theme are loaded from a shared asset folder, and everything else lives in this file.

Connections

A visible connection links this sentence to a circle on a small collage.

Another connection links this sentence to a square on the same collage.

Visitors who have the RW Reader extension installed get the extension's own reader instead, because the page also carries the embedded HDOC data.

The last connection points to a page on another site. This static host has no proxy, so opening it shows an alert.
